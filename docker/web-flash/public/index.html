Firmware update

Plane Radar

Update the device from this page over USB. No apps to install — use Chrome or Edge.

Loading version…

  1. Use the right browser Chrome or Edge on a computer, or Chrome on Android. Safari and iPhone are not supported.
  2. Plug in the radar Use a USB-C cable that can carry data (not charge-only).
  3. Put it in update mode Hold the BOOT button, tap RESET, then let go of BOOT.
  4. Install Click the button below, pick the USB device when asked, and wait until it finishes.
Web Serial is not available in this browser. Open this page in Chrome or Edge, or download the firmware file and flash with esptool-js at address 0x0. This page must be opened over HTTPS (or localhost) for USB install to work.

Prefer a manual flash? Download plane-radar.bin · flash at 0x0 · chip ESP32-C3

After it finishes

  • Unplug and plug the device back in (or tap RESET).
  • It should reconnect to your Wi‑Fi on its own.
  • If the map looks wrong, open http://plane-radar.local and check Setup (location / ZIP).
